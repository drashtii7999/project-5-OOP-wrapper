Python OOP Project: Employee Management System

📌 Project Description

The Employee Management System is a Python-based project developed using Object-Oriented Programming (OOP) concepts. It allows users to create and manage Person, Employee, and Manager records through a simple menu-driven interface.

🎯 Objectives

- To understand Object-Oriented Programming in Python.
- To implement inheritance and method overriding.
- To demonstrate encapsulation using private attributes.
- To use constructors and the "super()" function.
- To manage records using lists and display details.

🛠️ Technologies Used

- Programming Language: Python
- Code Editor: Visual Studio Code

✨ Features

1. Create a Person: Store a person's name and age.
2. Create an Employee: Store employee details, including ID and salary.
3. Create a Manager: Store manager details along with the department.
4. Show Details: Display saved Person, Employee, or Manager records.
5. Class Hierarchy Check: Use "issubclass()" to check inheritance relationships.
6. Exit: Close the program.

🧠 OOP Concepts Used

- Class and Object: Used to represent persons, employees, managers, and developers.
- Inheritance: "Employee" inherits from "Person"; "Manager" and "Developer" inherit from "Employee".
- Encapsulation: Employee ID and salary are stored as private attributes.
- Method Overriding: The "display()" method is redefined in derived classes.
- Constructor: The "__init__()" method initializes object attributes.
- "super()": Calls the parent class constructor and methods.
- Getter and Setter Methods: Used to access and update employee ID and salary.
- Destructor: The "__del__()" method is included in the Employee class.
- "issubclass()": Checks the inheritance relationship between classes.

▶️ How to Run the Project

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in Visual Studio Code.

4. Open the terminal.

5. Run the Python file using:
   
   python "project 5.py"
   
   Replace "project 5.py" with your actual Python filename if it is different.

6. Choose an operation from the menu and follow the instructions.
